This site showcases selected projects, work experience, research, and technical skills across simulation systems, interactive applications, web development, mobile development, and data/automation work.

## Live Demo

Visit the live site here: [adoyle.vercel.app](https://adoyle.vercel.app)

## About

This portfolio is the public home for my work as a software engineer. It highlights featured projects such as **Microchip Explorer** and **Planen**, along with additional work in Unreal Engine, mobile development, web development, Blender, and database design.

The site was originally based on the open-source **Nim** template and has been customized to better reflect my own experience, project structure, and personal branding. I expanded the original layout into a multi-page portfolio with project filtering, research context, and improved content organization.
